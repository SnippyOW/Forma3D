
Mac: the Mac equivalent of the exe is Forma.app, which you double-click the same way. Windows can't build it, so it has to be made once on a Mac or by GitHub, then you just click it. The Mac version hasn't been built or tested yet. It uses Metal for the viewport and compute without any settings.

Option A: build it on the Mac (one time)
1. Copy the C:\Test1 folder to the Mac.
2. Install Python 3.12 from python.org.
3. Open Terminal in that folder and run:
chmod +x scripts/build_macos.sh
./scripts/build_macos.sh
   This creates dist/Forma.app.
4. Drag Forma.app into Applications. From then on you open it by double-clicking or from the Dock or Launchpad, like any app.

Option B: let GitHub build it, so you never touch the Mac terminal
1. Put the project in a GitHub repository. The build workflow is already set up in .github/workflows/build.yml.
2. Every push builds both versions.
3. Under the repository's Actions tab, download Forma-macos-arm64.zip (and Forma-windows-x64.zip).
4. On the Mac, unzip it and drag Forma.app into Applications.

First launch on the Mac: the app isn't signed with a paid Apple developer certificate, so macOS blocks the first double-click. Right-click Forma.app, choose Open, then click Open again. You only need to do this once. If macOS says the app "is damaged", run this once in Terminal:
xattr -dr com.apple.quarantine /Applications/Forma.app

These builds are for Apple Silicon Macs (M1 and newer). Each time you change the code, rebuild: scripts\build_windows.ps1 on Windows (the desktop shortcut picks up the new exe automatically), and Option A or B for the Mac.
